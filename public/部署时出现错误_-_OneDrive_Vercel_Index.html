部署时出现错误

ItemNotFound

{
  "error": {
    "error": {
      "code": "itemNotFound",
      "message": "The resource could not be found.",
      "innerError": {
        "date": "2022-01-14T09:29:32",
        "request-id": "7fee4456-abd6-4258-aeb0-4f03ee43bd13",
        "client-request-id": "7fee4456-abd6-4258-aeb0-4f03ee43bd13"
      }
    }
  }
}

你没有指定一个有效的 OneDrive 进行共享。

  • 你分享的文件必须存放在 OneDrive 的一个文件夹里。
  • 你必须在 site.config.js 的 baseDirectory 处指定该文件夹的绝对路径。

    • 💬

    • Error 504

    { "error": { "code": "504", "message": "An error occurred with your deployment" } }

    这可能由多个错误引起，但可以确定的是你填错了 Redis URL 或者 site.config.js 里的内容。

  • 请检查 baseDirectory。如果你在旧版遇到了此问题，解决办法与上面的 itemNotFound 一致。
  • 请检查你在 Vercel 的 REDIS_URL 环境变量是否填好了 Redis URL。如果你使用 Upstash ，请启用 SSL 该 URL 长得很像 rediss://:xxx@us1-xxx.upstash.io:xxx ，请注意是 rediss 而非 redis ，是 ://:xx 而非 ://xx。
